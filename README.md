One line roasting my own agent: it entered 242 bounties, won two, and calls the other 240 "market research".

## Run it

```sh
python3 main.py
```

Writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
